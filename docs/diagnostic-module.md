# Модуль «Тегін сынақ тест → Толық аналитика»: полный сценарий

Бесплатная диагностика на лендинге eduapp.example.com:
**формат обучения → предмет → направление → короткий тест → полная аналитика с рекомендациями.**

Модуль уже работает в лендинге без сервера: вопросы лежат в коде, результат считается в браузере. Бэкенд можно подключить позже, менять интерфейс для этого не нужно (раздел 7).

| Что | Файл |
|---|---|
| Окно и шаги | `src/diagnostic/DiagnosticWizard.jsx` |
| Экран аналитики | `src/diagnostic/Report.jsx` |
| Подсчёт результата и правила рекомендаций | `src/diagnostic/report.js` |
| Предметы, темы, направления, банк вопросов | `src/diagnostic/questions.js` |
| Запросы к серверу и события аналитики | `src/diagnostic/api.js` |
| Все тексты (kk / ru) | `src/i18n.js` → разделы `diag` и `diagSection` |

---

## 1. Зачем этот модуль

- **Для ученика и родителя.** За 5 минут и без регистрации видно, какие темы западают и с чего начать подготовку.
- **Для EduApp.** Это лид-магнит: после аналитики идут кнопки «Тіркеліп, нәтижені сақтау» (регистрация) и «Толық сынақ тестті тапсыру» (платный полный тест).
- **Для SEO.** Блок `#diagnostic` на странице даёт полезный текст по запросам «математика», «НЗМ / НИШ», «БИЛ», «ҰБТ / ЕНТ».

## 2. Где открывается

| Точка входа | Где | `data-source` |
|---|---|---|
| «Тегін сынақ тест тапсыру» | Первый экран (Hero) | `hero` |
| «Тегін сынақ тест тапсыру» | Блок «Тегін диагностика» | `section` |
| «Тегін сынақ тест» | Фиолетовый баннер перед футером | `cta` |
| «Тегін тест» в меню | Шапка и футер | ведёт к блоку `#diagnostic` |

Все кнопки — обычные ссылки на `#diagnostic`. Без JavaScript они просто прокручивают к блоку с описанием, с JavaScript открывают окно. Ctrl/Cmd+клик работает как обычная ссылка.

## 3. Сценарий по шагам

Сверху окна — степпер: **Формат · Пән · Бағыт · Тест · Аналитика** (ru: Формат · Предмет · Направление · Тест · Аналитика).

### Шаг 1. Формат обучения
**«Қалай оқисың?»** / «Как ты учишься?»

| Вариант | kk | ru | На что влияет |
|---|---|---|---|
| `offline` | Оффлайн оқимын — мектепте немесе EduApp орталығында | Учусь офлайн — в школе или в центре EduApp | Рекомендация «Ұстазбен бірге талда» |
| `online` | Онлайн оқимын — бейнесабақтар, тікелей эфир | Учусь онлайн — видеоуроки, прямые эфиры | Рекомендация «Бейнесабақ + тікелей эфир» |

Клик по карточке выбирает её, и через 0,28 с открывается следующий шаг. Кнопка «Келесі» работает так же.

### Шаг 2. Предмет
**«Пәнді таңда»**: 8 вопросов, 4 темы по 2 вопроса.

| Предмет | Темы |
|---|---|
| Математика | Арифметика · Бөлшектер мен пайыздар · Теңдеулер және мәтінді есептер · Геометрия |
| Ағылшын тілі | Шақтар (Tenses) · Лексика · Предлогтар · Мәтінді түсіну |
| Қазақ тілі | Фонетика · Лексика · Морфология · Синтаксис |
| Логика | Сандық заңдылықтар · Аналогиялар · Логикалық тұжырымдар · Кеңістіктік ойлау |

### Шаг 3. Направление
**«Қайда дайындаласың?»**: НЗМ (НИШ) · БИЛ · РФМШ · ҰБТ (ЕНТ) · 3–10 сынып тесттері.

- Если выбрать «3–10 сынып», окно само прокручивается к выбору класса (3, 4, 5, 6, 7, 8, 9, 10). Тест начинается после выбора класса.
- От направления зависят текст рекомендаций и ссылка «Толық сынақ тестті тапсыру». Она ведёт на `eduapp.example.com/Tests?packageId=…`: для НЗМ — пакет 4 (kk) или 2 (ru), для классов добавляется `&gradeId=N`.

### Шаг 4. Тест
- Сверху показаны предмет, направление и секундомер (идёт только пока окно открыто).
- Дальше строка «Сұрақ 3 / 8 · Тақырып: Геометрия» и полоса прогресса.
- Вопрос и 4 варианта (A–D). Выбрать ответ можно мышью или клавишами **1–4**.
- «Келесі сұрақ» становится активной после выбора ответа. На последнем вопросе кнопка называется «Нәтижені көру».
- «Білмеймін» (Не знаю) засчитывается как пропуск. Пропуск не равен ошибке: в аналитике он показан отдельно.
- Правильный ответ во время теста не показывается: это диагностика, разбор будет в конце.
- «Артқа» возвращает к выбору направления. Тест начнётся заново.

### Шаг 5. Толық аналитика
Экран описан в разделе 4.

### Поведение окна
- Esc или крестик закрывают окно. Прогресс сохраняется, пока открыта страница: при повторном открытии ученик продолжит с того же места или снова увидит свой результат.
- Пока окно открыто, страница под ним не прокручивается. Фокус клавиатуры остаётся внутри окна, а после закрытия возвращается на кнопку, которая его открыла.
- Если переключить KZ ↔ RU во время теста, интерфейс и вопросы сразу переводятся, ответы сохраняются.

## 4. Экран «Толық аналитика»

Блоки сверху вниз:

| № | Блок | Что показывает |
|---|---|---|
| 1 | Шапка | «ТОЛЫҚ АНАЛИТИКА» и чипы выбора: формат · предмет · направление |
| 2 | **Жалпы нәтиже** | Крупный процент (например, 63%), «5 / 8 дұрыс жауап», уровень (иконка + подпись), шкала 0–100 с порогами 50 и 80, короткий вывод, число тем по статусам (Мықты / Орташа / Әлсіз) |
| 3 | Плитки | **Қателер үлесі**: % нерешённых (ошибки + пропуски) с расшифровкой. **Дұрыс жауап**: 5 / 8. **Жұмсалған уақыт**: м:сс и среднее на вопрос. **Ең әлсіз тақырып**: тема и % |
| 4 | **Жауаптар құрылымы** | Одна полоса «Дұрыс / Қате / Өткізілді» и легенда с числами и процентами |
| 5 | **Тақырыптар бойынша нәтиже** | Горизонтальная полоса 0–100% на каждую тему: значение на конце полосы, статус (иконка + подпись), пунктир на 50% и 80%, подсказка при наведении или фокусе |
| 6 | Күшті жақтарың / Жетілдіру керек | Два списка тем: от 80% и ниже 80% (сначала самые слабые) |
| 7 | **Жеке ұсыныстар** | Карточки рекомендаций (раздел 6) |
| 8 | Сұрақтар бойынша талдау (кесте) | Раскрывающаяся таблица: №, вопрос и тема, ответ ученика, правильный ответ, результат, время |
| 9 | Кнопки | «Толық сынақ тестті тапсыру», «Тіркеліп, нәтижені сақтау», «Қайта тапсыру», «Басқа пәнді таңдау» и пояснение, что это короткая диагностика |

### Правила оформления графиков
- **Цвета статусов:** мықты `#0ca30c`, орташа `#fab219`, әлсіз `#d03b3b`, пропуск `#94a3b8`. Цвет никогда не стоит один: рядом всегда иконка (✓ / ⚠ / ✕ / −) и подпись. Это важно для людей с нарушением цветового зрения.
- **Текст** всегда тёмный (ink), даже рядом с цветной полосой.
- **Полосы** толщиной 20 px, скругление 4 px только на конце. Начало (0%) прямое.
- **Каждая полоса** доступна с клавиатуры (`tabIndex=0`) и имеет полную подпись для экранного диктора (`role="img"` и `aria-label`).
- **Таблица** дублирует все данные графиков текстом.

## 5. Модель данных

### Вопрос (`questions.js` → API)
```json
{ "id": "m4", "topic": "geometry",
  "q": { "kk": "Тіктөртбұрыштың периметрі 30 см…", "ru": "Периметр прямоугольника 30 см…" },
  "a": ["36 см²", "45 см²", "54 см²", "63 см²"],
  "c": 2 }
```
`q` и `a` могут быть строкой или массивом (одинаково на обоих языках, как в английском) либо объектом `{ kk, ru }`.

### Выбор пользователя
```json
{ "format": "online", "subject": "math", "category": "grades", "grade": 6 }
```

### Отчёт (`buildReport()` в `report.js`)
```json
{
  "subjectId": "math", "total": 8, "correct": 5, "wrong": 2, "skipped": 1,
  "percent": 63, "errorPercent": 38, "timeSec": 204, "avgSec": 26, "level": "medium",
  "topics": [{ "id": "arith", "correct": 1, "total": 2, "percent": 50, "status": "medium" }],
  "strengths": [ … ], "weaknesses": [ … ],
  "items": [{ "id": "m1", "topic": "arith", "answer": 1, "right": 1, "result": "correct", "timeSec": 18 }]
}
```

## 6. Подсчёт и рекомендации

**Формулы**
- `percent` = верные / все × 100 (округление)
- `errorPercent` = (неверные + пропуски) / все × 100
- Процент темы = верные в теме / вопросы темы × 100
- Статус (и для темы, и для общего уровня): **≥ 80% — Мықты**, **50–79% — Орташа**, **< 50% — Әлсіз**. Пороги задаются в `THRESHOLDS` (`report.js`).

**Рекомендации** (`buildRecommendations()`), по порядку:
1. До 3 самых слабых тем: название, статус и совет из `topics[].tip` (например, для геометрии: «Периметр мен аудан формулаларын… есте сақта»).
2. Формат: оффлайн — «Ұстазбен бірге талда», онлайн — «Бейнесабақ + тікелей эфир».
3. Уровень и направление:
   - мықты — «Келесі қадам — толық тест ({cat})»;
   - орташа — «2 апталық қайталау жоспары»;
   - әлсіз — «Негізден баста».
4. Если были пропуски — «Өткізілген сұрақтар ({n})».
5. Темп:
   - в среднем меньше 12 с на вопрос и 2+ ошибки — «Асықпа»;
   - больше 90 с — «Уақытты басқару».

Тексты правил лежат в `i18n.js` → `diag.rec`, советы по темам — в `questions.js`.

## 7. API (когда появится бэкенд)

Включение: в `src/diagnostic/api.js` указать `API_BASE`, например `"https://eduapp.example.com/api"`.

### `GET /diagnostic/questions`
Параметры: `subject`, `category`, `grade` (для 3–10 классов), `lang` (`kk` | `ru`).
```json
{ "questions": [{ "id": "m1", "topic": "arith", "q": "…", "a": ["…","…","…","…"] }] }
```
- Нужно 8 вопросов, по 2 на каждую тему предмета (порядок тем чередовать).
- Для продакшна рекомендуем **не отдавать поле `c`** (правильный ответ) в браузер и проверять ответы на сервере (ниже).

### `POST /diagnostic/results`
```json
{
  "format": "online", "subject": "math", "category": "nis", "grade": null, "lang": "kk",
  "answers": [{ "questionId": "m1", "answer": 1, "timeSec": 18 }],
  "percent": 63, "topics": [ … ], "finishedAt": "2026-10-03T10:15:00.000Z"
}
```
Ответ: `{ "ok": true, "resultId": "…" }`. Если пользователь вошёл (cookie сессии), результат сохраняется в личный кабинет.

### Рекомендуемый вариант для продакшна: проверка на сервере
`POST /diagnostic/grade` принимает ответы без ключей и возвращает готовый отчёт в формате раздела 5. Тогда в `DiagnosticWizard.jsx` вызов `buildReport(...)` заменяется ответом сервера. Логику `report.js` можно перенести на сервер почти без изменений: это чистые функции без React.

## 8. События аналитики (GTM / Яндекс Метрика)

`track()` отправляет события в `window.dataLayer`, если счётчик установлен на странице.

| Событие | Когда | Параметры |
|---|---|---|
| `diag_open` | Открыли окно | `source`: hero / section / cta |
| `diag_format` | Выбран формат | `value` |
| `diag_subject` | Выбран предмет | `value` |
| `diag_category` | Выбрано направление | `value` |
| `diag_grade` | Выбран класс | `value` |
| `diag_test_start` | Начат тест | format, subject, category, grade |
| `diag_complete` | Показан результат | subject, category, percent |
| `diag_cta` | Клик по кнопке в аналитике | `cta`: full / register |

Воронка для отчёта: `diag_open → diag_test_start → diag_complete → diag_cta`.

## 9. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Все ответы «Білмеймін» | 0%, уровень «Бастапқы», рекомендации по всем темам и «Өткізілген сұрақтар» |
| Всё верно | 100%, слабых тем нет, «Келесі қадам — толық тест» |
| Сервер не ответил | «Сұрақтарды жүктеу мүмкін болмады» и кнопка «Қайталау» |
| Закрыли окно посреди теста | Прогресс и секундомер на паузе. После открытия тест продолжается |
| Перезагрузили страницу | Состояние сбрасывается (нужно хранить на сервере после регистрации) |
| Сменили язык в процессе | Тексты и вопросы переводятся, ответы сохраняются |
| Нет JavaScript | Кнопки ведут к блоку `#diagnostic` с описанием шагов |
| `prefers-reduced-motion` | Без анимаций и плавных прокруток |

## 10. Как добавить предмет или вопросы

1. В `questions.js` → `SUBJECTS` добавьте предмет: `id`, иконку (`Icon.*` из `Icons.jsx`), `name { kk, ru }` и 4 темы с `tip { kk, ru }`.
2. В `BANK` добавьте 8 вопросов (по 2 на тему), темы чередуются.
3. Проверьте правильные ответы `c` (индекс 0–3).

Больше ничего менять не нужно: карточка предмета, графики и рекомендации построятся сами.

## 11. Что можно добавить дальше

- 3–4 вопроса на тему: проценты по темам станут точнее (сейчас возможны только 0 / 50 / 100%).
- Разные вопросы под направление и класс, например НЗМ 6-сынып или ҰБТ (через API).
- Сохранение результата в личном кабинете и сравнение с прошлой попыткой.
- PDF-отчёт для родителей и отправка в WhatsApp.
- Подбор конкретных бейнесабақтар по слабым темам (ссылки на `/Courses`).
