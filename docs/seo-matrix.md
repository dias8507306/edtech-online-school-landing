# SEO-матрица: eduapp.example.com

## 1. URL и языки

| Язык | URL | `<html lang>` | hreflang |
|---|---|---|---|
| Казахский (основной, x-default) | `https://eduapp.example.com/` | `kk` | `kk-KZ` |
| Русский | `https://eduapp.example.com/ru/` | `ru` | `ru-KZ` |

- Обе страницы собираются в **готовый HTML** (пререндер React). Весь текст виден поисковикам без JavaScript, в том числе Яндексу.
- Переключатель KZ | RU — обычные ссылки на `/` и `/ru/`. Поисковик видит две отдельные страницы, а пользователь переключается мгновенно, без перезагрузки: адрес меняется через `history.pushState`, вместе с ним обновляются `lang`, title, description и canonical.
